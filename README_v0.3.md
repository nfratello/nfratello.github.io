# Frontier with Microsoft: prototype v0.3 for Ted (Nov 19, 2026)

Open Frontier_Home.html first. Keep every file in this folder together so the links and videos work.

- Frontier_Home.html: the front door to the Brief, The Hub and The Coach.
- Intelligent_Business_Process_Hub.html: The Hub.
  - Hospitality has 3 live scenarios.
  - The 11 other Brief industries each show 3 planned scenarios as placeholders.
  - You can filter by industry, persona and room of the house.
- Contoso_Hospitality_Cowork_Dynamics365_Storyboard.html: the full hospitality storyboard, with its 3 videos and captions.
- Frontier_Style_Guide.html: the shared look. It covers the rules, colors with contrast scores, type and product icons.
- frontier.css: the shared design tokens for every site.
- Scout_Prompt_Brief_and_Coach_Restyle.md: the prompt that applies the style to the Brief and the Coach.
